The Heights Restaurant-POS

The Heights Restaurant-POS — A Modern Point-of-Sale Solution

Problem

Many restaurants still rely on manual order taking and paper records, making it difficult to track table availability, customer orders, payments, and daily sales efficiently. This can lead to slower service, billing errors, and poor operational management.

Solution

The Heights Restaurant POS provides restaurant staff with a centralized dashboard to manage tables, process dine-in and takeout orders, track pending payments, generate receipts, and view reports. The system streamlines daily operations through an intuitive interface backed by Java Spring Boot APIs.

Tech Stack

  • HTML5 + CSS3
  • JavaScript
  • Java + Spring Boot
  • REST APIs

Highlights

  • Table Management
  • Order Processing
  • Payment Tracking
  • Sales Reports

Lessons Learned

Building this project improved my understanding of full-stack application development. I gained experience designing REST APIs with Spring Boot, connecting frontend components to backend services, implementing CRUD operations, and applying data structures such as queues, linked lists, and hash maps to solve practical restaurant management problems.

Tip Calculator Desktop Application — Java Swing Bill Splitting & Tip Calculator

Many people struggle to quickly calculate tips, split restaurant bills fairly, and keep track of previous calculations. Manual calculations are time-consuming and can lead to incorrect totals.

Tech Stack

  • Java
  • Swing
  • AWT Event Handling
  • Collections Framework

Highlights

  • User Authentication
  • Tip Calculation
  • Bill Splitting
  • Calculation History

Lessons Learned

Building this application strengthened my understanding of Java GUI development, event-driven programming, object-oriented design, input validation, and the effective use of collections such as HashMap and ArrayList to manage application data..

  • Node.js
  • Express.js
  • MySQL

Highlights

  • Role-Based Access
  • Student Records
  • Assessment Management
  • Transcript Generation

Lessons Learned

Building this project strengthened my understanding of enterprise application development, relational database design, REST API architecture, role-based authentication, and enforcing business rules through both application logic and database constraints. It also improved my ability to design normalized schemas and build scalable backend systems for real-world academic environments.
