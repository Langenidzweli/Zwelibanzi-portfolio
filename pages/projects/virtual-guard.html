Virtual Guard

Virtual Guard is an AI-powered retail surveillance platform designed to assist security teams by monitoring live CCTV feeds, detecting suspicious behaviour in real time, and providing actionable insights through an intelligent dashboard.

2026 • Personal Project • 8 Weeks
GitHub Live Demo Documentation
Overview

Modern retail stores rely on dozens of CCTV cameras to improve security, yet most surveillance systems still depend entirely on people watching multiple screens simultaneously. Virtual Guard introduces an intelligent monitoring layer that continuously analyses camera feeds, detects suspicious activity using computer vision, and immediately alerts security personnel through a central dashboard. Rather than replacing security teams, the platform acts as a digital assistant that helps them respond faster and investigate incidents more efficiently.

Problem

Security operators are expected to monitor numerous CCTV feeds at the same time, making it easy for suspicious behaviour to go unnoticed or be identified too late.

Solution

An AI-assisted surveillance platform capable of analysing live video streams, detecting predefined events, generating incident reports and notifying security teams in real time.

My Role

Designed the system architecture and developed the frontend, backend APIs, database design and AI integration as a complete full-stack project.

Architecture

Virtual Guard follows a modular architecture where the React dashboard communicates with a Spring Boot backend responsible for authentication, incident management and business logic. A dedicated Python service processes camera streams using computer vision models before storing detections in PostgreSQL and pushing updates to the dashboard.

Engineering Challenges

One of the biggest challenges was designing a system capable of handling continuous video streams while keeping the backend responsive. Another challenge involved integrating Java backend services with a Python-based AI detection pipeline in a way that remained modular, scalable and easy to maintain. Creating a dashboard that presented large amounts of security information without overwhelming users also required careful interface design.

Lessons Learned

Virtual Guard taught me that successful AI products are built on strong software engineering rather than machine learning alone. Developing this project strengthened my understanding of backend architecture, API design, database modelling, service integration and building scalable systems that combine multiple technologies into one cohesive platform.
